# For Tanu 🩷

A personal, romantic, and playful 3-page digital love letter website made with Next.js, Tailwind CSS, and Framer Motion for Tanishka (Tanu).

## ✨ Features
- **Page 1: A Little Place For You**: Hero section, 14 Things I Like About You with staggered reveal animations, and a cute poem.
- **Page 2: Little Letters**: 4 interactive "Open When" envelopes (Sad, Happy, Overwhelmed, Miss Me) + special converge-into-heart final card.
- **Page 3: Before You Go**: Sincere reassurance note, secret nickname reveal, handwritten poem card, and glowing interactive heart finale.
- **Atmosphere**: Soft pastel romantic color palette, gentle floating background particles, and ambient chime audio synthesizer.
- **Mobile First**: Built specifically for comfortable mobile reading.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
